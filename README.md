# 👑 Cartas a los Reyes Magos

Aplicación web interactiva y colaborativa para escribir, gestionar y sincronizar en tiempo real las cartas y listas de deseos a los Reyes Magos en familia.

🌐 **Web desplegada en GitHub Pages:** [https://josescobedov.github.io/cartas-reyes/](https://josescobedov.github.io/cartas-reyes/)

## ✨ Características

- ✉️ **Cartas personalizadas** para cada miembro de la familia.
- 🎁 **Listas de deseos dinámicas** con estados y prioridades.
- ⚡ **Sincronización en la nube en tiempo real** mediante Firebase Firestore y autenticación anónima.
- 📱 **Diseño responsive** adaptado para móviles, tablets y ordenadores con temática navideña.

## 🛠️ Tecnologías

- HTML5, Tailwind CSS y JavaScript moderno (ES Modules).
- Firebase App, Authentication y Firestore (v11).
- GitHub Pages para el despliegue continuo.
