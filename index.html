Cartas a los Reyes Magos

☁️ Activar guardado compartido en la nube

Para que cualquier persona con el enlace de tu GitHub Pages pueda añadir o tachar regalos y se guarde para todos sin iniciar sesión:

  1. Entra en console.firebase.google.com (gratis con tu cuenta Google) y crea un proyecto.
  2. Activa Authentication → Sign-in method → Anónimo.
  3. Crea una base de datos Firestore Database en modo prueba (o permitiendo lectura/escritura en artifacts/cartas-reyes-familia/public/data/cartas).
  4. Copia tu firebaseConfig en la parte superior del script de este index.html y súbelo a GitHub.
